# Jyothi Gelli - Portfolio Website

A professional portfolio website built with React.js showcasing my skills, projects, education, and achievements.

## 🚀 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Beautiful gradient designs and smooth animations
- **Easy Navigation**: Single-page application with smooth section transitions
- **Complete Portfolio**: Includes About, Education, Skills, Projects, Achievements, Certifications, and Contact sections

## 🛠️ Technologies Used

- React.js
- CSS3
- JavaScript (ES6+)

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/Gelli-Jyothi1243/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

The build folder will contain the optimized production-ready files.
